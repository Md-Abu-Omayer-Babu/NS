# Experiment 04: Implementation of Autokey Cipher for Classical Cryptographic Encryption and Decryption

## Problem Statement

Write a C++ program to implement the Autokey Cipher. The program should take a plaintext message and a prime key, encrypt the message using the Autokey technique, and then decrypt it back. In this cipher, the key stream is generated by combining an initial priming key with the plaintext itself.

## Introduction

The Autokey Cipher (also known as Autoclave Cipher) is a polyalphabetic substitution cipher invented by Blaise de Vigenère. Unlike the regular Vigenère Cipher which repeats a keyword, the Autokey Cipher extends the key by using the plaintext itself after the priming key is used up. This eliminates repeating patterns in the key stream, making it more secure.

### Mathematical Formula

Encryption: `Cᵢ = (Pᵢ + Kᵢ) mod 26`

Decryption: `Pᵢ = (Cᵢ - Kᵢ) mod 26`

Where the key stream K is:
- `K₁ =` Prime key (given by user)
- `Kᵢ = Pᵢ₋₁` (for i > 1, use the previous plaintext letter)

### Key Concepts

- **Priming key:** A single initial value used to encrypt the first letter.
- **Autokey (self-key):** After the first letter, the plaintext itself becomes the key.
- **Polyalphabetic:** Different letters can be encrypted with different key values.
- **Stream cipher:** Each letter is encrypted with a different key value, rather than a fixed shift.

### Example

Plaintext: `HELLO`, Prime Key = 7

Key stream: 7, H(7), E(4), L(11), L(11) → 7, 7, 4, 11, 11

- H(7): (7 + 7) mod 26 = 14 → O
- E(4): (4 + 7) mod 26 = 11 → L
- L(11): (11 + 4) mod 26 = 15 → P
- L(11): (11 + 11) mod 26 = 22 → W
- O(14): (14 + 11) mod 26 = 25 → Z

Ciphertext: `OLPWZ`

## Solution Explanation

The program works as follows:

1. **Input:** The user enters a plaintext string and a priming key (0-25).

2. **Encryption:**
   - Start with `prev = primeKey` (this is K₁).
   - For each letter:
     - Get its position P.
     - Compute `C = (P + prev) mod 26`.
     - Add the encrypted letter to ciphertext.
     - Set `prev = P` (the plaintext letter becomes the next key).

3. **Decryption:**
   - Start with `prev = primeKey`.
   - For each letter:
     - Get its position C.
     - Recover the plaintext: `P = (C - prev + 26) mod 26`.
     - Add the decrypted letter to result.
     - Set `prev = P` (use the recovered plaintext as the next key).

### How the Code Works

The `autokey(s, primeKey, enc)` function handles both encryption and decryption using a boolean flag:
- For encryption, the key is added to the plaintext.
- For decryption, the key is subtracted (26 - key is added).
- After each letter, `prev` is updated to the current plaintext character's position.

The key insight is that during decryption, even though we don't know the plaintext ahead of time, we recover it one letter at a time and immediately use it as the key for the next letter.
